# Globe View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a second 3D view, a whole procedural planet you can spin, with the landing sector marked by a glowing ring and a live card. You switch to it with `G` or a "View: Sector | Planet" control, and it flies smoothly back down to the sector whenever you act on the sector.

**Architecture:** There is still one r3f Canvas. The sector ("plane") scene stays mounted and keeps simulating. A planet scene with its own camera is mounted with r3f `createPortal`. A render switch (`useFrame(..., 1)`) draws whichever scene is up, and a root `events.filter` makes only that scene take pointer events. A small pure state machine (`viewMachine.js`, wrapped by the `viewMode.js` store) sequences each switch: the sector camera rises, a short fade plays, then the planet camera eases out from low over the site. The reverse dives in. Every drei `Html` label in the sector scene goes through a wrapper that hides it while the planet is up, and a Node test keeps it that way. The planet itself is a per-pixel procedural ShaderMaterial (3D gradient noise on the direction, seeded by `world.seed`), lit by the sector's own low sun and tone mapped by the sector's ACES settings. Left alone, it sways a little way towards the sun and back instead of spinning without end, so the site stays lit and in view.

**Tech Stack:** React 19, @react-three/fiber 9.8, @react-three/drei 10.7 (`OrbitControls`, `Html`), three 0.187 (WebGL2 `ShaderMaterial`, GLSL ES 3.0), Node 25 built-in test runner (`node --test`) for the pure modules, playwright-core with headless Chromium (swiftshader) for the UI check, and the mock sim (`web/mock/mock-server.mjs`).

## Look (design plan, from the frontend-design pass)

The client is mission control for an autonomous rover fleet on "Redshift-b". The theme says this is a dense, hazy super-Earth (2 g) under a low, warm red-dwarf sun. The audience is the operator and demo viewers. The planet view's job is context: where on this world the fleet is, how big the world is, and what state the sector is in, without leaving the dashboard.

**Color** (sRGB hex; everything except the ice, the night fill and the star tints comes from `lib/theme.js`):

| Token | Hex | Role |
|---|---|---|
| void | `#05070b` | Space. This is the dashboard's own background, so the planet floats in the HUD |
| dust, dustLight | `#86735f`, `#ad9a88` | Day-side plains and paler highland dust |
| rust | `#83695a` | Stains on the highlands (REGOLITH.strataA) |
| mare, mareDark | `#4f4741`, `#3b3431` | The dark plains |
| ice | `#eef1f2` | Polar caps and their frost fringe |
| airLow, airHigh, airDusk | `#d6a586`, `#8a6863`, `#3d3747` | The limb glow: peach low down, mauve higher, dusk past the terminator (the sector's own horizon, sky and zenith) |
| sunLight, twilight | `#ffdab4`, `#ffb27a` | Key light and the warm band at the terminator |
| signal | `#4fe0ef` | Only the landing marker and its leader line (the one accent) |

**Type:** Archivo Variable, the dashboard face.
- Card title: 13.5 px at weight 620.
- Values: 14 px at weight 560, tabular numerals.
- Labels and notes: 11.5 to 12.5 px in `--ink-3`, sentence case.
- No all-caps labels, no eyebrows, no monospace.

**Layout:** The planet sits centred in the part of the view the HUD leaves free (the same view offset the sector camera uses) and fills about 72 % of that height. The site is a little left of and above centre. It is lit from the upper left by the low sun, and the soft terminator crosses the right third of the disc (at home the sun stands about 17 degrees over the point under the camera: cosine 0.29). The card hangs to the right of the marker over the darker side, where text reads best, joined to the ring by a 1 px cyan leader line. The planet legend takes the sector legend's place at the bottom left. The View row sits in the controls panel's last group, directly above the Graphics row it copies, so the Follow buttons keep their places.

```
+----------+-------------------------------------------+----------+
| Controls |          .   *        .        hazards    | Sidebar  |
| Follow   |              .-~~~~~~~~-.                 |          |
| View S|P |           .'  day   ::::'.   night        |          |
| Graphics |          /     (o)--+-------------------+ |          |
|          |         |   marker  | Landing sector    | |          |
|          |          \          | 120 x 120 m, not  | |          |
|          |           '.        | to scale ...      | |          |
| Planet   |             '-....-'+-------------------+ |          |
| legend   |   .        *             .                |          |
+----------+-------------------------------------------+----------+
```

**Principles:**
1. The planet is the hero. Everything around it is quieter than in the sector view: no layer toggles light up, and nothing animates except the planet.
2. One accent. Cyan marks only what you can act on: the marker ring and its card.
3. Honest scale. The ring is a symbol, and both the card and the legend say "not to scale". The radius is derived, and the legend says how ("Earth's density at 2.0 g").
4. Light tells the story: a low sun on the site, a soft terminator band, thick air glowing on the day limb and fading into dusk.
5. Motion only when asked (the flights between views), plus one slow idle sway: left alone, the planet turns about 20 degrees towards the sun over a minute and eases back, then again. Its sun turns with it, so the site stays in daylight, and the sway only ever shows more of the day side, so the site, its card and a mostly lit disc stay in view however long the planet is left. An endless turn would carry the site to the night side within two minutes. Reduced motion means none.

**Review against the brief.** The generic version of this brief is a blue Earth-like ball with a neon graticule, a holographic ring and a "PLANET VIEW" caps title. ros2_gazebo's globe used a graticule and a scan sweep. Changes made:
- No graticule or grid. The surface itself carries the interest.
- The rim uses this world's peach and mauve sky, not a generic blue.
- The twilight goes warm and then mauve, not Mars-blue: the theme's sky is peach and mauve, and a blue dusk would contradict the sector view.
- No title over the planet. The name lives in the legend, in the same type as the sector legend.

`web/test/globe-math.test.mjs`:

```js
import test from 'node:test'
import assert from 'node:assert/strict'
import { SUN_DIR } from '../src/scene/sceneConstants.js'
import {
  GLOBE_FOV,
  IDLE_SWAY,
  MAX_DIST,
  formatKm,
  formatLatLon,
  gravityG,
  hashSeed,
  homeDir,
  homeDistance,
  idleSway,
  latLonToDir,
  lerpPose,
  planetLook,
  planetName,
  planetRadiusKm,
  seedLook,
  siteFrame,
  siteFromSeed,
  slerp,
  smoother,
  sunDirFor,
  turnY,
  wrapAngle,
} from '../src/globe/globeMath.js'

const dot = (a, b) => a[0] * b[0] + a[1] * b[1] + a[2] * b[2]
const len = (a) => Math.hypot(a[0], a[1], a[2])
const near = (a, b, eps = 1e-9) => a.forEach((v, i) => assert.ok(Math.abs(v - b[i]) < eps, `${a} vs ${b}`))

test('radius from gravity at Earth density, with a readable label', () => {
  assert.equal(planetRadiusKm(2), 12742)
  assert.equal(planetRadiusKm(1), 6371)
  assert.equal(planetRadiusKm(NaN), 6371)
  assert.equal(formatKm(12742), '12,742 km')
  assert.equal(formatKm(950), '950 km')
  assert.equal(formatKm(1234567), '1,234,567 km')
})

test('gravity and name from the world, with fallbacks', () => {
  assert.equal(gravityG({ gravity_g: 2 }), 2)
  assert.ok(Math.abs(gravityG({ gravity: 19.62 }) - 2) < 1e-9)
  assert.equal(gravityG(null), 2)
  assert.equal(planetName({ name: 'Redshift-b' }), 'Redshift-b')
  assert.equal(planetName({ name: '  ' }), 'Unnamed planet')
  assert.equal(planetName(undefined), 'Unnamed planet')
})

test('the site comes from the seed, near the equator', () => {
  assert.equal(hashSeed(42), 2279835011)
  assert.deepEqual(siteFromSeed(42), { lat: 4.4, lon: 44.9 })
  assert.deepEqual(siteFromSeed('42'), siteFromSeed(42))
  assert.deepEqual(siteFromSeed('abc'), { lat: -0.8, lon: -26.4 })
  assert.notDeepEqual(siteFromSeed(43), siteFromSeed(42))
  for (let s = 0; s < 200; s++) {
    const { lat, lon } = siteFromSeed(s)
    assert.ok(Math.abs(lat) <= 32 && lon >= -180 && lon < 180, `${s}: ${lat}, ${lon}`)
  }
})

test('latitude and longitude read like a map', () => {
  assert.equal(formatLatLon({ lat: 12.3, lon: -103.7 }), '12.3° N, 103.7° W')
  assert.equal(formatLatLon({ lat: -5, lon: 20 }), '5.0° S, 20.0° E')
  assert.equal(formatLatLon(siteFromSeed(42)), '4.4° N, 44.9° E')
})

test('directions: y is north, longitude 0 faces +z, east is +x there', () => {
  near(latLonToDir(0, 0), [0, 0, 1])
  near(latLonToDir(90, 30), [0, 1, 0], 1e-12)
  near(latLonToDir(0, 90), [1, 0, 0], 1e-12)
  const f = siteFrame(4.4, 44.9)
  for (const v of [f.up, f.east, f.north]) assert.ok(Math.abs(len(v) - 1) < 1e-12)
  assert.ok(Math.abs(dot(f.up, f.east)) < 1e-12)
  assert.ok(Math.abs(dot(f.up, f.north)) < 1e-12)
  assert.ok(Math.abs(dot(f.east, f.north)) < 1e-12)
  assert.ok(f.north[1] > 0, 'north points towards the north pole')
})

test('the site is in daylight under the sector sun, lit from the west-north-west', () => {
  const f = siteFrame(4.4, 44.9)
  const sun = sunDirFor(f)
  const k = Math.hypot(...SUN_DIR)
  assert.ok(Math.abs(len(sun) - 1) < 1e-12)
  assert.ok(Math.abs(dot(sun, f.up) - SUN_DIR[1] / k) < 1e-9)
  assert.ok(dot(sun, f.east) < 0)
  assert.ok(dot(sun, f.north) > 0)
})

test('home view: a little east and south of overhead, the planet filling the free view', () => {
  const f = siteFrame(4.4, 44.9)
  const h = homeDir(f)
  assert.ok(dot(h, f.up) > 0.9)
  assert.ok(dot(h, f.east) > 0)
  assert.ok(dot(h, f.north) < 0)
  assert.ok(Math.abs(homeDistance(GLOBE_FOV) - 4.5171) < 1e-3)
  assert.ok(Math.abs(homeDistance(GLOBE_FOV, 0.88) - 5.1046) < 1e-3)
  assert.ok(homeDistance(GLOBE_FOV, 0.5) > homeDistance(GLOBE_FOV, 1))
  assert.equal(homeDistance(GLOBE_FOV, 0.05), MAX_DIST)
})

test('poses ease: slerped direction, log distance, the short way round', () => {
  const a = { dir: [0, 0, 1], dist: 1.3, spin: 3 }
  const b = { dir: [1, 0, 0], dist: 5.2, spin: -3 }
  const p0 = lerpPose(a, b, 0)
  near(p0.dir, a.dir, 1e-12)
  assert.ok(Math.abs(p0.dist - 1.3) < 1e-12)
  const p1 = lerpPose(a, b, 1)
  near(p1.dir, b.dir, 1e-12)
  assert.ok(Math.abs(p1.dist - 5.2) < 1e-9)
  const mid = lerpPose(a, b, 0.5)
  assert.ok(Math.abs(mid.dist - Math.sqrt(1.3 * 5.2)) < 1e-9)
  assert.ok(Math.abs(mid.spin - Math.PI) < 1e-9, `spin ${mid.spin}`)
  assert.ok(Math.abs(len(slerp([0, 0, 1], [0.6, 0.8, 0], 0.37)) - 1) < 1e-12)
  assert.ok(Math.abs(len(slerp([0, 0, 1], [0, 0, -1], 0.5)) - 1) < 1e-12)
  assert.equal(smoother(0), 0)
  assert.equal(smoother(1), 1)
  assert.equal(smoother(0.5), 0.5)
  assert.equal(smoother(2), 1)
  assert.ok(Math.abs(wrapAngle(-6) - (2 * Math.PI - 6)) < 1e-12)
  assert.ok(Math.abs(wrapAngle(7)) < Math.PI)
})

test('the idle sway turns towards the sun and back, so the site and the middle of the disc stay lit', () => {
  assert.equal(idleSway(0), 0)
  assert.ok(Math.abs(idleSway(Math.PI) - IDLE_SWAY) < 1e-12)
  assert.ok(Math.abs(idleSway(2 * Math.PI)) < 1e-12)
  near(turnY([0, 0, 1], Math.PI / 2), [1, 0, 0], 1e-12) // the same turn as three.js rotation.y
  for (let s = 0; s < 200; s++) {
    const { lat, lon } = siteFromSeed(s)
    const f = siteFrame(lat, lon)
    const sun = sunDirFor(f)
    const h = homeDir(f)
    for (let k = 0; k <= 8; k++) {
      // The camera at home, in the frame of the planet turned by the sway.
      const c = turnY(h, -idleSway((k / 8) * Math.PI))
      assert.ok(dot(c, sun) > 0.25, `seed ${s}: the sun is at ${dot(c, sun)} over the middle of the disc`)
      assert.ok(dot(c, f.up) > 0.9, `seed ${s}: the site faces the camera at ${dot(c, f.up)}`)
    }
  }
})

test('surface knobs per seed, deterministic and in range', () => {
  assert.deepEqual(seedLook(42), seedLook(42))
  assert.notDeepEqual(seedLook(42).offset, seedLook(43).offset)
  for (let s = 0; s < 50; s++) {
    const l = seedLook(s)
    assert.ok(l.maria >= 0.06 && l.maria <= 0.18)
    assert.ok(l.craters >= 0.45 && l.craters <= 0.8)
```

```js
// Directions are [x, y, z] arrays in the planet's own frame: y is the spin axis (north up),
// longitude 0 faces +z and east is +x there. Angles are degrees unless a name says not.

export const EARTH_RADIUS_KM = 6371
export const GLOBE_FOV = 35 // the planet camera's vertical field of view, degrees
export const START_ALT = 0.3 // the planet camera arrives this high over the site, planet radii
export const MIN_DIST = 1.35 // zoom limits, planet radii from the centre
export const MAX_DIST = 9
export const MARKER_R = 0.085 // landing ring radius, planet radii (a symbol, not to scale)
export const HOME_FILL = 0.72 // at home the planet fills this share of the free view height
const HOME_EAST = 0.3 // the home view leans east of the site, towards the terminator,
const HOME_SOUTH = 0.1 // and a little south, so the site sits above the middle
const SITE_MAX_LAT = 32 // the caps stay in view and the site never hides behind a pole

const clamp = (v, lo, hi) => Math.min(hi, Math.max(lo, v))
const dot = (a, b) => a[0] * b[0] + a[1] * b[1] + a[2] * b[2]
const cross = (a, b) => [a[1] * b[2] - a[2] * b[1], a[2] * b[0] - a[0] * b[2], a[0] * b[1] - a[1] * b[0]]
const comb = (terms) => terms.reduce((o, [k, v]) => [o[0] + k * v[0], o[1] + k * v[1], o[2] + k * v[2]], [0, 0, 0])
const round1 = (v) => Math.round(v * 10) / 10

export function normalize(a) {
  const l = Math.hypot(a[0], a[1], a[2]) || 1
  return [a[0] / l, a[1] / l, a[2] / l]
}

// Same density as Earth: surface gravity grows with the radius (g = 4/3 pi G rho R).
export const planetRadiusKm = (g) => Math.round((Number.isFinite(g) && g > 0 ? g : 1) * EARTH_RADIUS_KM)
export const formatKm = (km) => `${String(Math.round(km)).replace(/\B(?=(\d{3})+(?!\d))/g, ',')} km`

export function gravityG(world) {
  if (Number.isFinite(world?.gravity_g) && world.gravity_g > 0) return world.gravity_g
  if (Number.isFinite(world?.gravity) && world.gravity > 0) return world.gravity / 9.81
  return 2
}

export const planetName = (world) => (typeof world?.name === 'string' && world.name.trim() ? world.name.trim() : 'Unnamed planet')

// FNV-1a over the seed's text, so numbers and strings both give a well-mixed 32-bit value.
export function hashSeed(seed) {
  const s = String(seed ?? 0)
  let h = 2166136261
  for (let i = 0; i < s.length; i++) {
    h ^= s.charCodeAt(i)
    h = Math.imul(h, 16777619)
  }
  return h >>> 0
}

// The landing site, fixed per seed (tenths of a degree, so labels and drawing agree).
export function siteFromSeed(seed) {
  const r = mulberry(hashSeed(seed) ^ 0x51e5)
  const lat = round1((r() * 2 - 1) * SITE_MAX_LAT)
  const lon = round1(r() * 360 - 180)
  return { lat, lon: lon >= 180 ? -180 : lon }
}

export function formatLatLon({ lat, lon }) {
  const ns = lat >= 0 ? 'N' : 'S'
  const ew = lon >= 0 ? 'E' : 'W'
  return `${Math.abs(lat).toFixed(1)}° ${ns}, ${Math.abs(lon).toFixed(1)}° ${ew}`
}

export function latLonToDir(lat, lon) {
  const a = (lat * Math.PI) / 180
  const b = (lon * Math.PI) / 180
  return [Math.cos(a) * Math.sin(b), Math.sin(a), Math.cos(a) * Math.cos(b)]
}

// Local axes at a point on the planet: up (out of the ground), east and north.
export function siteFrame(lat, lon) {
  const up = latLonToDir(lat, lon)
  const east = normalize(cross([0, 1, 0], up))
  const north = cross(up, east)
  return { up, east, north }
}

// The sector's sun (SUN_DIR: x east, y up, z south) placed over the site: the same low sun
// from the west-north-west, so the site is in daylight and the shading matches the sector.
export const sunDirFor = (f) => normalize(comb([[SUN_DIR[0], f.east], [SUN_DIR[1], f.up], [-SUN_DIR[2], f.north]]))

// The home view direction (from the planet's centre to the camera).
export const homeDir = (f) => normalize(comb([[1, f.up], [HOME_EAST, f.east], [-HOME_SOUTH, f.north]]))

// Distance from the centre at which the planet fills `fill` of a view `frac` of the canvas
// height tall (the part the HUD leaves free): its angular radius a has sin a = 1 / d.
export function homeDistance(fovDeg, frac = 1, fill = HOME_FILL) {
  const t = Math.tan((fovDeg * Math.PI) / 360) * fill * clamp(frac, 0.2, 1)
  return clamp(1 / Math.sin(Math.atan(t)), MIN_DIST + 0.4, MAX_DIST)
}

export function smoother(t) {
  const x = clamp(t, 0, 1)
  return x * x * x * (x * (x * 6 - 15) + 10)
}

export const wrapAngle = (a) => a - 2 * Math.PI * Math.floor((a + Math.PI) / (2 * Math.PI))

// Spherical interpolation between unit vectors.
export function slerp(a, b, t) {
  const w = Math.acos(clamp(dot(a, b), -1, 1))
  if (w < 1e-6) return normalize(comb([[1 - t, a], [t, b]]))
  if (Math.PI - w < 1e-6) {
    // Opposite directions: turn through any perpendicular.
    const p = normalize(Math.abs(a[1]) < 0.9 ? cross(a, [0, 1, 0]) : cross(a, [1, 0, 0]))
    return normalize(comb([[Math.cos(Math.PI * t), a], [Math.sin(Math.PI * t), p]]))
  }
  const s = Math.sin(w)
  return comb([[Math.sin((1 - t) * w) / s, a], [Math.sin(t * w) / s, b]])
}

// Planet camera poses: { dir (camera direction from the centre), dist (planet radii), spin
// (the planet's turn about its axis, radians) }. Distance eases in log space, so equal steps
// feel equal at any height, and the spin takes the short way round.
export function lerpPose(a, b, t) {
  const k = clamp(t, 0, 1)
  return {
    dir: slerp(a.dir, b.dir, k),
    dist: Math.exp(Math.log(a.dist) + (Math.log(b.dist) - Math.log(a.dist)) * k),
    spin: a.spin + wrapAngle(b.spin - a.spin) * k,
  }
}

// A turn by `a` radians about the spin axis, the same as three.js `rotation.y = a`. So
// turnY(v, -spin) is a world direction seen from the turned planet.
export const turnY = (v, a) => [v[0] * Math.cos(a) + v[2] * Math.sin(a), v[1], v[2] * Math.cos(a) - v[0] * Math.sin(a)]

// The idle motion (GlobeRig.jsx): not an endless spin, which would carry the site to the
// night side within two minutes, but a slow sway from home out to IDLE_SWAY and back, at
// rest at both ends. A positive turn brings the camera's side of the planet towards the
// sun, so the middle of the disc only gets brighter and the site stays facing the camera.
export const IDLE_SWAY = 0.35 // radians, about 20 degrees
export const idleSway = (phase) => (IDLE_SWAY * (1 - Math.cos(phase))) / 2

// Per-world surface knobs for the planet shader (planetMaterial.js).
export function seedLook(seed) {
  const r = mulberry(hashSeed(seed) ^ 0x2545f491)
  const span = () => r() * 97 - 48.5
  return {
    offset: [span(), span(), span()], // where in noise space this world's surface comes from
    maria: 0.06 + r() * 0.12, // noise level above which the dark plains begin
    craters: 0.45 + r() * 0.35, // share of lattice cells that hold a crater
    capN: 0.86 + r() * 0.06, // sine of the latitude where the northern ice starts
    capS: 0.83 + r() * 0.08, // and the southern
    rust: 0.25 + r() * 0.5, // how much rusty stain the highlands get
  }
}

// Everything the planet view needs to know about a world.
export function planetLook(world) {
  const seed = world?.seed ?? 0
  const site = siteFromSeed(seed)
  const frame = siteFrame(site.lat, site.lon)
  const g = gravityG(world)
  return { seed, site, frame, sun: sunDirFor(frame), surface: seedLook(seed), name: planetName(world), g, radiusKm: planetRadiusKm(g) }
}
```

```js
// The switch between the sector view ('plane') and the planet view ('globe') as a small
// state machine, pure so Node can test it. Times are seconds on any one clock.
//   view    the view asked for
//   render  the scene being drawn
//   phase   idle | out (leaving the drawn scene: the sector camera rises, or the planet
//           camera dives) | fade (a short fade to black, then render switches) | in (the
//           new camera eases in)
//   since   when the phase began; seq counts accepted requests; home counts the 0 key
//   via     how the drawn scene was reached: 'start', 'fade', 'turn' (turned round
//           half-way, so nothing was faded) or 'instant' (reduced motion)

export const DUR = { out: 0.75, fade: 0.2, in: 1.5 }
const EPS = 1e-6
const VIEWS = new Set(['plane', 'globe'])

export const initialView = () => ({ view: 'plane', render: 'plane', phase: 'idle', since: 0, seq: 0, home: 0, via: 'start' })

export function requestView(s, want, now, instant = false) {
  if (!VIEWS.has(want)) return s
  if (instant) {
    if (s.view === want && s.render === want && s.phase === 'idle') return s
    return { ...s, view: want, render: want, phase: 'idle', since: now, seq: s.seq + 1, via: 'instant' }
  }
  if (s.view === want) return s
  // Still drawing the scene asked for (turned round during the rise, the dive or the fade):
  // ease back in from wherever the camera is. Otherwise leave the drawn scene first.
  if (s.render === want) return { ...s, view: want, phase: 'in', since: now, seq: s.seq + 1, via: 'turn' }
  return { ...s, view: want, phase: 'out', since: now, seq: s.seq + 1 }
}

// Moves to the next phase when the current one has run its time; the same object otherwise.
export function advance(s, now) {
  const dt = now - s.since + EPS
  if (s.phase === 'out' && dt >= DUR.out) return { ...s, phase: 'fade', since: now }
  if (s.phase === 'fade' && dt >= DUR.fade) return { ...s, render: s.view, phase: 'in', since: now, via: 'fade' }
  if (s.phase === 'in' && dt >= DUR.in) return { ...s, phase: 'idle', since: now }
  return s
}

export const frameHome = (s) => ({ ...s, home: s.home + 1 })

// How far through the current phase, 0 to 1 (1 when idle).
export function progress(s, now) {
  const d = DUR[s.phase]
  return d ? Math.min(1, Math.max(0, (now - s.since) / d)) : 1
}

// Selectors. They return primitives, so they are safe for useSyncExternalStore.
export const globeShown = (s) => s.render === 'globe'
export const planeLabelsShown = (s) => s.view === 'plane' && s.render === 'plane'
export const fading = (s) => s.phase === 'fade'
export const globeSettled = (s) => s.render === 'globe' && s.view === 'globe' && s.phase === 'idle'
export const globeCardShown = (s) => s.render === 'globe' && s.view === 'globe'
```

```js
// The sector camera's side of the switch to the planet (see CameraRig.jsx). Plain arrays
// in three.js axes (x east, y up, z south), so Node can test it.

export const RISE_RATE = 4.2 // per second: how fast the camera eases up to the top-down pose
export const RETURN_OUT = 1.8 // back from the planet it starts this much further out, then glides in

// Straight above the middle of the map, high enough that the whole sector fills `fill` of
// the view height: the moment before the planet takes over. A hair south of vertical, so
// the orbit controls keep a heading and north stays up on screen.
export function topDownPose(map, fovDeg, fill = 0.62) {
  const cx = map.ox + map.width / 2
  const cy = map.oy + map.depth / 2
  const h = (map.minH + map.maxH) / 2
  const reach = Math.max(map.width, map.depth, 1) / 2
  const d = reach / (fill * Math.tan((fovDeg * Math.PI) / 360))
  return { target: [cx, h, -cy], position: [cx, h + d, -cy + d * 0.002] }
}

// Orbit controls keep a damped remainder of the last drag. With damping off for one update
// it is applied at once and cleared, so it cannot resume after a scripted move.
export function settleControls(c) {
  if (!c) return
  const damping = c.enableDamping
  c.enableDamping = false
  c.update()
  c.enableDamping = damping
}
```

```js
import { mulberry } from '../scene/proceduralTextures.js'

// The planet view's sky as plain arrays: the same stars on every visit and every world
// (never Math.random, so screenshots are repeatable). About 40 % lie near a band, like a
// galaxy seen edge on; brightness falls off steeply, so most stars are faint.

export const STAR_RADIUS = 300
const k = Math.hypot(0.32, 0.86, -0.4)
export const BAND = [0.32 / k, 0.86 / k, -0.4 / k] // the band's pole, tilted against the planet's axis

export function starData(count) {
  const rand = mulberry(0x5eed1)
  const position = new Float32Array(count * 3)
  const mag = new Float32Array(count)
  const kind = new Uint8Array(count) // 0 warm, 1 white, 2 cool
  const phase = new Float32Array(count)
  for (let i = 0; i < count; i++) {
    const z = rand() * 2 - 1
    const a = rand() * Math.PI * 2
    const s = Math.sqrt(1 - z * z)
    let d = [s * Math.cos(a), z, s * Math.sin(a)]
    if (rand() < 0.4) {
      // Pulled onto the band: keep only a small, roughly normal height above its plane.
      const h = d[0] * BAND[0] + d[1] * BAND[1] + d[2] * BAND[2]
      const keep = 0.12 * (rand() + rand() + rand() - 1.5)
      const q = [d[0] - BAND[0] * (h - keep), d[1] - BAND[1] * (h - keep), d[2] - BAND[2] * (h - keep)]
      const l = Math.hypot(q[0], q[1], q[2])
      if (l > 1e-6) d = [q[0] / l, q[1] / l, q[2] / l]
    }
    position[i * 3] = d[0] * STAR_RADIUS
    position[i * 3 + 1] = d[1] * STAR_RADIUS
    position[i * 3 + 2] = d[2] * STAR_RADIUS
    mag[i] = Math.pow(rand(), 5)
    const t = rand()
    kind[i] = t < 0.2 ? 0 : t < 0.82 ? 1 : 2
    phase[i] = rand() * Math.PI * 2
  }
  return { position, mag, kind, phase }
}
```

```js
import { useSyncExternalStore } from 'react'
import { stopPlacing } from '../lib/placement.js'
import { reducedMotion } from '../scene/sceneConstants.js'
import { advance, frameHome as bumpHome, initialView, requestView } from './viewMachine.js'

// Which 3D view is up, the landing sector ('plane') or the whole planet ('globe'), and
// where the switch between them is (see viewMachine.js). Client-side only: the 3D rigs
// read it every frame, React reads it through useViewMode.

export { fading, globeCardShown, globeSettled, globeShown, planeLabelsShown } from './viewMachine.js'

const clock = () => performance.now() / 1000
let state = initialView()
const subs = new Set()

function set(next) {
  if (next === state) return
  state = next
  subs.forEach((fn) => fn())
}

export const viewMode = {
  get: () => state,
  // Ask for a view. Hazard placement never survives the trip to the planet. With
  // prefers-reduced-motion the switch is instant.
  request(want, { instant = reducedMotion } = {}) {
    if (want === 'globe') stopPlacing()
    set(requestView(state, want, clock(), instant))
  },
  toggle(opts) {
    viewMode.request(state.view === 'globe' ? 'plane' : 'globe', opts)
  },
  // The 0 key on the planet: glide back to the home view.
  frameHome() {
    if (state.render === 'globe') set(bumpHome(state))
  },
  // Called once per frame (GlobeLayer's ViewClock) to move the switch along.
  tick(now = clock()) {
    set(advance(state, now))
  },
  subscribe(fn) {
    subs.add(fn)
    return () => subs.delete(fn)
  },
}

export const useViewMode = (selector) => useSyncExternalStore(viewMode.subscribe, () => selector(state))

// Anything that acts on the sector calls this first. On the planet, or on the way to it,
// it starts the flight back down and returns true.
export function leaveGlobe() {
  if (state.view !== 'globe' && state.render !== 'globe') return false
  viewMode.request('plane')
  return true
}
```

```js
  const stack = []
  for (const ch of src.replace(/\/\/.*$/gm, '')) {
```

```js
import * as THREE from 'three'

// Stars as round, soft points with a bright core. HUD-like: no tone mapping, so a star is
// the colour it says. Twinkle (High graphics, no reduced motion) is a slow, small flicker.

export const STAR_VERT = /* glsl */ `
attribute float aMag;
attribute vec3 aTint;
attribute float aPhase;
uniform float uTime;
uniform float uPx;
uniform float uTwinkle;
varying vec3 vCol;
void main() {
  gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
  float tw = 1.0 + uTwinkle * 0.2 * sin(uTime * (0.9 + aPhase * 0.25) + aPhase * 5.0);
  gl_PointSize = uPx * mix(1.2, 3.6, aMag);
  vCol = aTint * mix(0.14, 1.0, aMag) * tw;
}
`

export const STAR_FRAG = /* glsl */ `
varying vec3 vCol;
void main() {
  vec2 c = gl_PointCoord * 2.0 - 1.0;
  float r2 = dot(c, c);
  if (r2 > 1.0) discard;
  gl_FragColor = vec4(vCol * exp(-r2 * 5.0), 1.0);
  #include <colorspace_fragment>
}
`

export function makeStarMaterial() {
  return new THREE.ShaderMaterial({
    vertexShader: STAR_VERT,
    fragmentShader: STAR_FRAG,
    uniforms: { uTime: { value: 0 }, uPx: { value: 1 }, uTwinkle: { value: 0 } },
    transparent: true,
    depthWrite: false,
    blending: THREE.AdditiveBlending,
    toneMapped: false,
  })
}
```

```jsx
import { useEffect, useRef } from 'react'
import { useFrame, useThree } from '@react-three/fiber'
import { OrbitControls } from '@react-three/drei'
import { applyShift, freeRect } from '../scene/CameraRig.jsx'
import { GLOBE_FOV, MAX_DIST, MIN_DIST, homeDir, homeDistance } from './globeMath.js'
import { settleControls } from './planeTransition.js'
import { viewMode } from './viewMode.js'
import { globeRefs } from './globeDebug.js'

// The planet camera: orbits the centre with north up, framed in the part of the view the
// HUD leaves free (the same view offset as the sector camera). First version: it shows
// the home view when the planet is first drawn and again on the 0 key.
export function GlobeRig({ look, spin }) {
  const camera = useThree((s) => s.camera)
  const size = useThree((s) => s.size)
  const controls = useRef(null)
  const st = useRef({ shift: null, drawn: false, home: viewMode.get().home, glide: null, dragging: false, lastInput: 0 })

  useEffect(() => {
    globeRefs.rig = st.current
    return () => {
      globeRefs.rig = null
    }
  }, [])

  const freeFrac = () => {
    const f = freeRect(size)
    return (f.y1 - f.y0) / Math.max(1, size.height)
  }
  const homePose = () => ({ dir: homeDir(look.frame), dist: homeDistance(GLOBE_FOV, freeFrac()), spin: 0 })
  const put = (p) => {
    camera.position.set(p.dir[0] * p.dist, p.dir[1] * p.dist, p.dir[2] * p.dist)
    camera.up.set(0, 1, 0)
    camera.lookAt(0, 0, 0)
    if (spin.current) spin.current.rotation.y = p.spin
  }

  useFrame((_, dt) => {
    const c = controls.current
    const v = viewMode.get()
    const s = st.current
    if (c) c.enabled = v.render === 'globe' && v.view === 'globe' && v.phase === 'idle'
    if (v.render !== 'globe') {
      s.drawn = false
      return
    }
    const aspect = size.width / Math.max(1, size.height)
    if (camera.aspect !== aspect) {
      camera.aspect = aspect
      camera.updateProjectionMatrix()
    }
    applyShift(s, camera, size, freeRect(size), dt)
    if (!s.drawn || v.home !== s.home) {
      s.drawn = true
      s.home = v.home
      if (c) settleControls(c)
      put(homePose())
    }
  })

  return (
    <OrbitControls
      ref={controls}
      enablePan={false}
      enableDamping
      dampingFactor={0.07}
      rotateSpeed={0.45}
      zoomSpeed={0.7}
      minDistance={MIN_DIST}
      maxDistance={MAX_DIST}
      minPolarAngle={0.25}
      maxPolarAngle={Math.PI - 0.25}
      onStart={() => {
        const s = st.current
        s.dragging = true
        s.lastInput = performance.now() / 1000
      }}
      onEnd={() => {
        const s = st.current
        s.dragging = false
        s.lastInput = performance.now() / 1000
```

```jsx
import { useEffect, useMemo } from 'react'
import { createPortal, useFrame, useThree } from '@react-three/fiber'
import * as THREE from 'three'
import { VOID } from '../lib/theme.js'
import { GLOBE_FOV } from './globeMath.js'
import { viewMode } from './viewMode.js'
import { globeRefs } from './globeDebug.js'
import { GlobeWorld } from './GlobeWorld.jsx'

const rootOf = (o) => {
  while (o.parent) o = o.parent
  return o
}

// Moves the view switch along once per frame, before any rig or the render reads it.
function ViewClock() {
  useFrame(() => viewMode.tick(), -2)
  return null
}

// Draws the scene that is up. A positive priority takes the render over from r3f.
function RenderSwitch({ scene, camera }) {
  useFrame((state) => {
    if (viewMode.get().render === 'globe') state.gl.render(scene, camera)
    else state.gl.render(state.scene, state.camera)
  }, 1)
  return null
}

// v7 planet view (spec section 5). One canvas: the sector scene stays mounted, and keeps
// following the sim, while the planet scene and its own camera are drawn instead. The
// planet scene is an r3f portal, so its objects get pointer events and its label the page.
export function GlobeLayer({ onSelect }) {
  const gl = useThree((s) => s.gl)
  const rootScene = useThree((s) => s.scene)
  const get = useThree((s) => s.get)
  const setEvents = useThree((s) => s.setEvents)
  const scene = useMemo(() => {
    const s = new THREE.Scene()
    s.background = new THREE.Color(VOID)
    return s
  }, [])
  const camera = useMemo(() => new THREE.PerspectiveCamera(GLOBE_FOV, 1, 0.01, 400), [])

  // three.js raycasts hidden objects too: only the scene being drawn takes pointer events.
  useEffect(() => {
    const prev = get().events.filter
    setEvents({
      filter: (hits, state) => {
        const want = viewMode.get().render === 'globe' ? scene : rootScene
        const mine = hits.filter((h) => rootOf(h.object) === want)
        return prev ? prev(mine, state) : mine
      },
    })
    return () => setEvents({ filter: prev })
  }, [get, setEvents, scene, rootScene])

  // Compile the planet's shaders when it is first asked for (during the rise), so the
  // first frame after the fade does not stall. A session that never opens it pays nothing.
  useEffect(() => {
    let done = false
    return viewMode.subscribe(() => {
      if (done || viewMode.get().view !== 'globe') return
      done = true
      // compile() only starts the driver's work (three checks the result on first use);
      // compileAsync() warns where KHR_parallel_shader_compile is missing.
      gl.compile(scene, camera)
    })
  }, [gl, scene, camera])

  useEffect(() => {
    globeRefs.camera = camera
    globeRefs.gl = gl
    return () => {
      globeRefs.camera = null
      globeRefs.gl = null
    }
  }, [camera, gl])

  return (
    <>
      <ViewClock />
      <RenderSwitch scene={scene} camera={camera} />
      {createPortal(<GlobeWorld onSelect={onSelect} />, scene, { camera })}
    </>
  )
}
```

````js
import * as THREE from 'three'
import { GLOBE } from './globePalette.js'

// The planet's surface and its air as three.js ShaderMaterials (WebGL2, GLSL ES 3.0; three
// adds the precision, the matrices and cameraPosition). Both end with three's tone mapping
// and colour space chunks, so the planet gets the sector's ACES exposure.
// Noise: gnoised() is Inigo Quilez's 3D gradient noise with analytic derivatives (MIT,
// iquilezles.org/articles/gradientnoise); hash33() is Dave Hoskins' "Hash without Sine"
// (MIT). The rest is ours.

// Look knobs (Task 15 tunes these on screenshots).
export const LOOK = {
  sunI: 2.2, // sunlight on the day side
  lommel: 0.45, // share of Lommel-Seeliger (dusty ground, bright to the limb) against Lambert
  relief: 0.03, // bump strength of the fine fractal noise
  craterRelief: 0.3, // bump strength of the craters
  haze: 0.55, // air over the day side of the disc, strongest at the limb
  night: 1.0, // starlight on the night side
  airH: 0.016, // air scale height, planet radii (a thick, hazy atmosphere)
  airI: 1.1, // brightness of the glow on the limb
}
export const AIR_R = 1.06 // the air shell's radius

// Shared by the planet and its air: the position on the sphere and the camera, both in
// the planet's own frame (the planet group spins, so modelMatrix is a pure rotation).
export const GLOBE_VERT = /* glsl */ `
varying vec3 vPos;
varying vec3 vCam;
void main() {
  vPos = position;
  vCam = transpose(mat3(modelMatrix)) * (cameraPosition - modelMatrix[3].xyz);
  gl_Position = projectionMatrix * viewMatrix * modelMatrix * vec4(position, 1.0);
}
`

const NOISE = /* glsl */ `
vec3 hash33(vec3 p3) {
  p3 = fract(p3 * vec3(0.1031, 0.1030, 0.0973));
  p3 += dot(p3, p3.yxz + 33.33);
  return fract((p3.xxy + p3.yxx) * p3.zyx);
}

// Gradient noise, about -1 to 1: x is the value, yzw its gradient.
vec4 gnoised(vec3 x) {
  vec3 i = floor(x);
  vec3 f = fract(x);
  vec3 u = f * f * f * (f * (f * 6.0 - 15.0) + 10.0);
  vec3 du = 30.0 * f * f * (f * (f - 2.0) + 1.0);
  vec3 ga = hash33(i + vec3(0.0, 0.0, 0.0)) * 2.0 - 1.0;
  vec3 gb = hash33(i + vec3(1.0, 0.0, 0.0)) * 2.0 - 1.0;
  vec3 gc = hash33(i + vec3(0.0, 1.0, 0.0)) * 2.0 - 1.0;
  vec3 gd = hash33(i + vec3(1.0, 1.0, 0.0)) * 2.0 - 1.0;
  vec3 ge = hash33(i + vec3(0.0, 0.0, 1.0)) * 2.0 - 1.0;
  vec3 gf = hash33(i + vec3(1.0, 0.0, 1.0)) * 2.0 - 1.0;
  vec3 gg = hash33(i + vec3(0.0, 1.0, 1.0)) * 2.0 - 1.0;
  vec3 gh = hash33(i + vec3(1.0, 1.0, 1.0)) * 2.0 - 1.0;
  float va = dot(ga, f - vec3(0.0, 0.0, 0.0));
  float vb = dot(gb, f - vec3(1.0, 0.0, 0.0));
  float vc = dot(gc, f - vec3(0.0, 1.0, 0.0));
  float vd = dot(gd, f - vec3(1.0, 1.0, 0.0));
  float ve = dot(ge, f - vec3(0.0, 0.0, 1.0));
  float vf = dot(gf, f - vec3(1.0, 0.0, 1.0));
  float vg = dot(gg, f - vec3(0.0, 1.0, 1.0));
  float vh = dot(gh, f - vec3(1.0, 1.0, 1.0));
  float v = va + u.x * (vb - va) + u.y * (vc - va) + u.z * (ve - va)
    + u.x * u.y * (va - vb - vc + vd) + u.y * u.z * (va - vc - ve + vg)
    + u.z * u.x * (va - vb - ve + vf) + (-va + vb + vc - vd + ve - vf - vg + vh) * u.x * u.y * u.z;
  vec3 d = ga + u.x * (gb - ga) + u.y * (gc - ga) + u.z * (ge - ga)
    + u.x * u.y * (ga - gb - gc + gd) + u.y * u.z * (ga - gc - ge + gg)
    + u.z * u.x * (ga - gb - ge + gf) + (-ga + gb + gc - gd + ge - gf - gg + gh) * u.x * u.y * u.z
    + du * (vec3(vb - va, vc - va, ve - va)
      + u.yzx * vec3(va - vb - vc + vd, va - vc - ve + vg, va - vb - ve + vf)
      + u.zxy * vec3(va - vb - ve + vf, va - vb - vc + vd, va - vc - ve + vg)
      + u.yzx * u.zxy * (-va + vb + vc - vd + ve - vf - vg + vh));
  return vec4(v, d);
}

// Fractal noise with its gradient; each octave rotated so the lattice never lines up.
const mat3 OCT = mat3(0.00, 0.80, 0.60, -0.80, 0.36, -0.48, -0.60, -0.48, 0.64);
vec4 fbmd(vec3 p, int octaves) {
  float v = 0.0;
  vec3 d = vec3(0.0);
  float a = 0.5;
  mat3 m = mat3(1.0); // transpose of d(octave coordinates) / dp so far
  for (int i = 0; i < 8; i++) {
    if (i >= octaves) break;
    vec4 n = gnoised(p);
    v += a * n.x;
    d += a * (m * n.yzw);
    a *= 0.5;
    p = OCT * p * 2.02;
    m = 2.02 * m * transpose(OCT);
  }
  return vec4(v, d);
}

// One layer of craters: at most one per cell of a 3D lattice (scale cells per planet
// radius), radius up to a third of a cell. Adds the height gradient (a bowl and a raised
// rim) to g; returns how much of p lies on a crater floor (x) and on a rim (y).
vec2 craters(vec3 p, float scale, float density, float salt, inout vec3 g) {
  vec3 q = p * scale;
  vec3 base = floor(q - 0.5);
  vec2 marks = vec2(0.0);
  for (int k = 0; k < 8; k++) {
    vec3 cell = base + vec3(float(k & 1), float((k >> 1) & 1), float((k >> 2) & 1));
    vec3 jit = hash33(cell + salt);
    vec3 rnd = hash33(cell.zxy + salt * 1.7 + 41.3);
    if (rnd.x > density) continue;
    float R = mix(0.12, 0.34, rnd.y * rnd.y);
    vec3 dv = q - (cell + 0.25 + 0.5 * jit);
    float dist = length(dv);
    float x = dist / R;
    if (x >= 1.32) continue;
    float depth = 0.42 * R / scale;
    float slope = 0.0;
    if (x < 1.0) {
      slope += depth * 2.0 * x;
      marks.x = max(marks.x, 1.0 - x * x);
    }
    float s = (x - 1.0) / 0.32;
    if (abs(s) < 1.0) {
      float w = 1.0 - s * s;
      slope += 0.3 * depth * 2.0 * w * (-2.0 * s) / 0.32;
      marks.y = max(marks.y, w * w);
    }
    g += slope * dv * (scale / (R * max(dist, 1e-4)));
  }
  return marks;
}
`

export const PLANET_FRAG = /* glsl */ `
uniform vec3 uSun;
uniform vec3 uOffset;
uniform float uMaria;
uniform float uCraters;
uniform float uCapN;
uniform float uCapS;
uniform float uRust;
uniform float uRelief;
uniform float uCraterRelief;
uniform float uSunI;
uniform float uLommel;
uniform float uHazeI;
uniform float uNightI;
uniform vec3 uDust;
uniform vec3 uDustLight;
uniform vec3 uRustCol;
uniform vec3 uMare;
uniform vec3 uMareDark;
uniform vec3 uIce;
uniform vec3 uSunCol;
uniform vec3 uTwilight;
uniform vec3 uHaze;
uniform vec3 uNight;
varying vec3 vPos;
varying vec3 vCam;

#ifdef GLOBE_HQ
  #define OCTAVES 7
#else
  #define OCTAVES 4
#endif
#define FREQ 2.2
${NOISE}
void main() {
  vec3 n0 = normalize(vPos);

  // Continents: a slow noise sets the dark plains (maria) and where rust stains the dust.
  vec4 low = fbmd(n0 * 1.1 + uOffset * 0.37, 3);
  float mare = smoothstep(uMaria, uMaria + 0.12, low.x);
  float rough = 1.0 - 0.65 * mare; // the plains are smooth lava

  // Relief, as a height gradient for the lighting: fine noise plus craters (fewer on the
  // younger maria). Graphics Low keeps four octaves and the biggest craters only.
  vec4 hi = fbmd(n0 * FREQ + uOffset, OCTAVES);
  vec3 g = hi.yzw * (FREQ * uRelief * rough);
  vec3 cg = vec3(0.0);
  vec2 crater = craters(n0, 7.0, uCraters * (1.0 - 0.6 * mare), 3.17, cg);
#ifdef GLOBE_HQ
  crater = max(crater, craters(n0, 19.0, uCraters * (1.0 - 0.4 * mare), 7.73, cg));
  crater = max(crater, craters(n0, 47.0, uCraters, 13.31, cg));
#endif
  g += cg * uCraterRelief;

  // Albedo: dust and paler highland dust, rust stains, the dark plains, crater marks.
  float tone = smoothstep(-0.35, 0.45, hi.x * 1.4 + gnoised(n0 * 5.3 + uOffset.zxy).x * 0.35);
  vec3 alb = mix(uDust, uDustLight, tone);
  float rust = uRust * smoothstep(-0.05, 0.35, gnoised(n0 * 2.6 + uOffset.yzx).x * 0.4 - low.x);
  alb = mix(alb, uRustCol, rust * 0.75);
  alb = mix(alb, mix(uMare, uMareDark, smoothstep(uMaria, uMaria + 0.35, low.x)), mare);
  alb *= 1.0 - 0.16 * crater.x + 0.1 * crater.y * (1.0 - mare);

  // Polar ice with ragged edges, and a frost fringe on the bright ground around it.
  float rag = 0.05 * low.x + 0.02 * hi.x + 0.025 * gnoised(n0 * 13.0 + uOffset.yzx).x;
  float edgeN = uCapN + rag;
  float edgeS = uCapS - rag;
  float cap = max(smoothstep(edgeN, edgeN + 0.018, n0.y), smoothstep(edgeS, edgeS + 0.018, -n0.y));
  float frost = max(smoothstep(edgeN - 0.08, edgeN, n0.y), smoothstep(edgeS - 0.08, edgeS, -n0.y)) * (1.0 - cap);
  alb = mix(alb, mix(alb, uIce, 0.5), frost * tone);
  alb = mix(alb, uIce * (0.86 + 0.14 * tone), cap);
  g *= 1.0 - 0.75 * cap;

  // Light. The bumped normal shades the relief; the geometric day side sets the terminator.
  vec3 L = normalize(uSun);
  vec3 V = normalize(vCam - n0);
  vec3 N = normalize(n0 - (g - dot(g, n0) * n0));
  float geo = dot(n0, L);
  float mu0 = max(dot(N, L), 0.0);
  float mu = max(dot(N, V), 0.02);
  float brdf = mix(mu0, 2.0 * mu0 / (mu0 + mu), uLommel);
  float day = smoothstep(-0.10, 0.22, geo); // soft: the thick air carries light past the edge
  vec3 col = alb * uSunCol * (uSunI * brdf * day);
  // A warm band at the terminator, and faint starlight on the night side.
  float dusk = smoothstep(-0.18, 0.02, geo) * (1.0 - smoothstep(0.02, 0.26, geo));
  col += alb * uTwilight * (0.16 * dusk);
  col += alb * uNight * uNightI;
  // The air over the disc: haze builds towards the day limb.
  float limb = pow(1.0 - max(dot(n0, V), 0.0), 3.0);
  col += uHaze * (uHazeI * limb * smoothstep(-0.2, 0.4, geo));
  // A faint glint on the ice.
  vec3 H = normalize(L + V);
  col += uSunCol * (0.1 * cap * day * pow(max(dot(N, H), 0.0), 36.0));

  gl_FragColor = vec4(col, 1.0);
  #include <tonemapping_fragment>
  #include <colorspace_fragment>
}
`

// The glow of the air around the limb: for each view ray past the planet, the air density
// at its closest approach (exponential with height), lit where the sun is up there, with a
// little forward scattering when the sun is behind the planet. Peach low, mauve higher,
// dusk past the terminator, a trace of night glow on the dark limb.
export const AIR_FRAG = /* glsl */ `
uniform vec3 uSun;
uniform vec3 uLow;
uniform vec3 uHigh;
uniform vec3 uDusk;
uniform float uH;
uniform float uR;
uniform float uI;
varying vec3 vPos;
varying vec3 vCam;
void main() {
  vec3 rd = normalize(vPos - vCam);
  vec3 q = vCam + rd * max(-dot(vCam, rd), 0.0);
  float b = length(q);
  float alt = max(b - 1.0, 0.0);
  float dens = exp(-alt / uH) * smoothstep(uR, uR - 0.012, b);
  vec3 L = normalize(uSun);
  float sunUp = dot(q / max(b, 1e-4), L);
  float lit = smoothstep(-0.32, 0.28, sunUp);
  float fwd = 1.0 + 2.5 * pow(max(dot(rd, L), 0.0), 8.0);
  vec3 air = mix(uLow, uHigh, smoothstep(0.0, 3.5 * uH, alt));
  air = mix(uDusk, air, smoothstep(-0.12, 0.3, sunUp));
  vec3 c = air * (dens * lit * fwd * uI) + uDusk * (dens * 0.05);
  gl_FragColor = vec4(c, 1.0);
  #include <tonemapping_fragment>
  #include <colorspace_fragment>
}
`

const col = (hex) => new THREE.Color(hex)

export function makePlanetMaterial(high) {
  return new THREE.ShaderMaterial({
    vertexShader: GLOBE_VERT,
    fragmentShader: PLANET_FRAG,
    defines: high ? { GLOBE_HQ: '' } : {},
    uniforms: {
      uSun: { value: new THREE.Vector3(0, 0, 1) },
      uOffset: { value: new THREE.Vector3() },
      uMaria: { value: 0.12 },
      uCraters: { value: 0.6 },
      uCapN: { value: 0.88 },
      uCapS: { value: 0.87 },
      uRust: { value: 0.5 },
      uRelief: { value: LOOK.relief },
      uCraterRelief: { value: LOOK.craterRelief },
      uSunI: { value: LOOK.sunI },
      uLommel: { value: LOOK.lommel },
      uHazeI: { value: LOOK.haze },
      uNightI: { value: LOOK.night },
      uDust: { value: col(GLOBE.dust) },
      uDustLight: { value: col(GLOBE.dustLight) },
      uRustCol: { value: col(GLOBE.rust) },
      uMare: { value: col(GLOBE.mare) },
      uMareDark: { value: col(GLOBE.mareDark) },
      uIce: { value: col(GLOBE.ice) },
      uSunCol: { value: col(GLOBE.sunLight) },
      uTwilight: { value: col(GLOBE.twilight) },
      uHaze: { value: col(GLOBE.haze) },
      uNight: { value: col(GLOBE.night) },
    },
  })
}

export function makeAirMaterial() {
  return new THREE.ShaderMaterial({
    vertexShader: GLOBE_VERT,
    fragmentShader: AIR_FRAG,
    side: THREE.BackSide,
    transparent: true,
    depthWrite: false,
    blending: THREE.AdditiveBlending,
    uniforms: {
      uSun: { value: new THREE.Vector3(0, 0, 1) },
      uLow: { value: col(GLOBE.airLow) },
      uHigh: { value: col(GLOBE.airHigh) },
      uDusk: { value: col(GLOBE.airDusk) },
      uH: { value: LOOK.airH },
      uR: { value: AIR_R },
      uI: { value: LOOK.airI },
    },
  })
}

// Per-world values from planetLook() (globeMath.js).
export function applyLook(planet, air, look) {
  const u = planet.uniforms
  const s = look.surface
  u.uSun.value.set(look.sun[0], look.sun[1], look.sun[2]).normalize()
  u.uOffset.value.set(s.offset[0], s.offset[1], s.offset[2])
  u.uMaria.value = s.maria
  u.uCraters.value = s.craters
  u.uCapN.value = s.capN
  u.uCapS.value = s.capS
  u.uRust.value = s.rust
  air.uniforms.uSun.value.copy(u.uSun.value)
}
````

```jsx
// The planet: a unit sphere whose surface is worked out per pixel from the direction (no
// texture, so no seams and no pole pinch), inside a shell of glowing air. Graphics Low
// compiles the same shader without GLOBE_HQ and uses fewer triangles.
export function Planet({ look, high }) {
  const geo = useMemo(() => new THREE.SphereGeometry(1, high ? 192 : 96, high ? 128 : 64), [high])
  const airGeo = useMemo(() => new THREE.SphereGeometry(AIR_R, high ? 96 : 64, high ? 64 : 32), [high])

  const air = useMemo(makeAirMaterial, [])
  // Before the next frame, so the first draw already has this world's look.
  useLayoutEffect(() => applyLook(mat, air, look), [mat, air, look])
  useEffect(() => {
    globeRefs.planet = mat
    return () => {
      if (globeRefs.planet === mat) globeRefs.planet = null
    }
  }, [mat])
  useEffect(() => () => geo.dispose(), [geo])
  useEffect(() => () => airGeo.dispose(), [airGeo])
  useEffect(() => () => mat.dispose(), [mat])
  useEffect(() => () => air.dispose(), [air])
  return (
    <>
      <mesh geometry={geo} material={mat} />
      <mesh geometry={airGeo} material={air} renderOrder={2} />
    </>
  )
}
```

```js
import * as THREE from 'three'
import { GLOBE } from './globePalette.js'

// The landing marker, drawn on a square in the ground's plane: a crisp ring (radius half
// the square), a soft glow around it, a faint fill, the sector as a small square outline
// at the centre, and a pulse that runs outwards every few seconds. The ring adds light over
// a soft dark backing (premultiplied alpha), so it reads on bright dust and dark plains
// alike. HUD-like: no tone mapping, so it is the signal cyan.

export const MARKER_VERT = /* glsl */ `
varying vec2 vUv;
void main() {
  vUv = uv * 2.0 - 1.0;
  gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}
`

export const MARKER_FRAG = /* glsl */ `
uniform vec3 uColor;
uniform float uTime;
uniform float uFade;
uniform float uHover;
uniform float uPulse;
varying vec2 vUv;
void main() {
  float r = length(vUv);
  float aa = fwidth(r) * 1.5;
  float ring = 1.0 - smoothstep(0.03, 0.03 + aa, abs(r - 0.5));
  float glow = exp(-pow((r - 0.5) / 0.13, 2.0)) * 0.5;
  float fill = (1.0 - smoothstep(0.0, 0.5, r)) * 0.08;
  vec2 a = abs(vUv);
  float box = 1.0 - smoothstep(0.012, 0.012 + fwidth(a.x + a.y) * 1.5, abs(max(a.x, a.y) - 0.1));
  float t = fract(uTime * 0.3);
  float pulse = uPulse * (1.0 - t) * exp(-pow((r - mix(0.5, 0.95, t)) / 0.035, 2.0)) * 0.55;
  float lum = (ring * 0.95 + glow + fill + box * 0.9 + pulse) * (1.0 + 0.5 * uHover);
  float shade = exp(-pow((r - 0.5) / 0.22, 2.0)) * 0.45 + (1.0 - smoothstep(0.0, 0.55, r)) * 0.15;
  float alpha = clamp(lum + shade, 0.0, 1.0) * uFade;
  if (alpha < 0.002) discard;
  gl_FragColor = vec4(uColor * (lum * uFade), alpha);
  #include <colorspace_fragment>
}
`

export function makeMarkerMaterial() {
  return new THREE.ShaderMaterial({
    vertexShader: MARKER_VERT,
    fragmentShader: MARKER_FRAG,
    uniforms: {
      uColor: { value: new THREE.Color(GLOBE.signal) },
      uTime: { value: 0 },
      uFade: { value: 1 },
      uHover: { value: 0 },
      uPulse: { value: 1 },
    },
    transparent: true,
    depthWrite: false,
    blending: THREE.NormalBlending, // with premultipliedAlpha: src ONE, dst ONE_MINUS_SRC_ALPHA
    premultipliedAlpha: true,
    toneMapped: false,
  })
}
```

```jsx
import * as THREE from 'three'

import { globeRefs } from './globeDebug.js'
import { SectorCard } from './SectorCard.jsx'

const HOME_SURF = homeDistance(GLOBE_FOV, 0.88) - 1 // camera height over the ground at home
const _p = new THREE.Vector3()
const _c = new THREE.Vector3()

// The landing sector on the planet: a cyan ring lying on the ground at the site, about the
// same size on screen at any zoom (a symbol: the sector itself is far too small to see),
// and the live card beside it. Clicking the ring flies back down. Its hit disc is invisible
// but still raycast, and the planet has no handlers, so a click only counts when the site
// faces the camera.
export function SiteMarker({ look, onSelect }) {
  const group = useRef(null)
  const card = useRef(null)
  const st = useRef({ facing: 1, over: false, hover: 0 })
  const camera = useThree((s) => s.camera)
  const cardShown = useViewMode(globeCardShown)
  const mat = useMemo(makeMarkerMaterial, [])
  const geo = useMemo(() => new THREE.PlaneGeometry(MARKER_R * 4, MARKER_R * 4), [])
  const hitGeo = useMemo(() => new THREE.CircleGeometry(MARKER_R * 1.7, 40), [])
  const hitMat = useMemo(() => new THREE.MeshBasicMaterial(), [])
  useEffect(
    () => () => {
      mat.dispose()
      geo.dispose()
      hitGeo.dispose()
      hitMat.dispose()
    },
    [mat, geo, hitGeo, hitMat],
  )
  useEffect(
    () => () => {
      document.body.style.cursor = ''
    },
    [],
  )
  useEffect(() => {
    globeRefs.site = group.current
    return () => {
      globeRefs.site = null
    }
  }, [])

  // Flat on the ground at the site: local x east, y north, z up.
  useLayoutEffect(() => {
    const g = group.current
    const { up, east, north } = look.frame
    const basis = new THREE.Matrix4().makeBasis(new THREE.Vector3(...east), new THREE.Vector3(...north), new THREE.Vector3(...up))
    g.quaternion.setFromRotationMatrix(basis)
    g.position.set(up[0], up[1], up[2]).multiplyScalar(1.003)
  }, [look])

  useFrame((state, dt) => {
    const g = group.current
    const s = st.current
    if (!g) return
    if (viewMode.get().render !== 'globe') {
      if (s.over) {
        s.over = false
        document.body.style.cursor = ''
      }
      return
    }
    g.getWorldPosition(_p)
    s.facing = _c.copy(camera.position).sub(_p).normalize().dot(_p.normalize())
    g.scale.setScalar(THREE.MathUtils.clamp((camera.position.length() - 1) / HOME_SURF, 0.35, 1.8))
    s.hover += ((s.over ? 1 : 0) - s.hover) * (1 - Math.exp(-Math.min(dt, 0.1) * 10))
    const u = mat.uniforms
    u.uFade.value = THREE.MathUtils.smoothstep(s.facing, 0.02, 0.25)
    u.uHover.value = s.hover
    u.uPulse.value = reducedMotion ? 0 : 1
    u.uTime.value = state.clock.elapsedTime
    // Imperative, so React re-renders of the card never reset it.
    if (card.current) card.current.toggleAttribute('data-away', s.facing < 0.3)
  })

  const facingUs = () => st.current.facing > 0.2
  const click = (e) => {
    e.stopPropagation()
    if (e.delta > 4 || !facingUs()) return
    leaveGlobe()
  }
  const over = (e) => {
    if (!facingUs()) return
    e.stopPropagation()
    st.current.over = true
    document.body.style.cursor = 'pointer'
  }
  const out = () => {
    st.current.over = false
    document.body.style.cursor = ''
  }

  return (
    <group ref={group}>
      <mesh geometry={geo} material={mat} renderOrder={3} />
      <mesh geometry={hitGeo} material={hitMat} visible={false} onClick={click} onPointerOver={over} onPointerOut={out} />
      {cardShown && (
        <Html zIndexRange={[18, 0]} wrapperClass="globe-card-wrap">
          <SectorCard cardRef={card} onSelect={onSelect} />
        </Html>
      )}
    </group>
  )
}
```

```js
  function rise(c, s, dt) {
    if (!s.saved) {
```

```jsx
import { useEffect, useRef } from 'react'
import { useFrame, useThree } from '@react-three/fiber'
import { OrbitControls } from '@react-three/drei'
import { reducedMotion } from '../scene/sceneConstants.js'
import { applyShift, freeRect } from '../scene/CameraRig.jsx'
import { GLOBE_FOV, MAX_DIST, MIN_DIST, START_ALT, homeDir, homeDistance, idleSway, lerpPose, smoother } from './globeMath.js'
import { progress } from './viewMachine.js'
import { settleControls } from './planeTransition.js'
import { viewMode } from './viewMode.js'
import { globeRefs } from './globeDebug.js'

const SPIN_AFTER = 8 // seconds without input before the planet starts to turn
const SWAY_PERIOD = 120 // seconds for one idle sway: out to IDLE_SWAY (globeMath.js) and back
const HOME_GLIDE = 1.2 // seconds, the 0 key and a new world

// The planet camera. It orbits the centre with north up, framed in the part of the view
// the HUD leaves free (the sector camera's view offset). Arriving from the sector it
// starts low over the site, where the sector camera left off looking down, and eases out
// to the home view; leaving, it dives back to that spot before the fade. Left alone for a
// while the planet sways slowly about 20 degrees towards the sun and back (its sun turns
// with it, so the site stays lit, and the sway never turns the site away); a drag pauses
// that, 0 glides back home, and so does a new world (Reset sim on the planet). With
// reduced motion every move is instant and nothing turns by itself.
export function GlobeRig({ look, spin }) {
  const camera = useThree((s) => s.camera)
  const size = useThree((s) => s.size)
  const controls = useRef(null)
  const st = useRef({ shift: null, phaseKey: '', phase: '', drawn: false, from: null, home: viewMode.get().home, seed: null, glide: null, lastInput: 0, dragging: false, sway: 0 })

  useEffect(() => {
    globeRefs.rig = st.current
    return () => {
      globeRefs.rig = null
    }
  }, [])

  const freeFrac = () => {
    const f = freeRect(size)
    return (f.y1 - f.y0) / Math.max(1, size.height)
  }
  const homePose = () => ({ dir: homeDir(look.frame), dist: homeDistance(GLOBE_FOV, freeFrac()), spin: 0 })
  const closePose = () => ({ dir: look.frame.up, dist: 1 + START_ALT, spin: 0 })
  const pose = () => {
    const d = camera.position.length() || 1
    return { dir: [camera.position.x / d, camera.position.y / d, camera.position.z / d], dist: d, spin: spin.current ? spin.current.rotation.y : 0 }
  }
  const put = (p) => {
    camera.position.set(p.dir[0] * p.dist, p.dir[1] * p.dist, p.dir[2] * p.dist)
    camera.up.set(0, 1, 0)
    camera.lookAt(0, 0, 0)
    if (spin.current) spin.current.rotation.y = p.spin
    // Every scripted move ends at spin 0 (the home and close poses), so the next idle sway
    // starts from its beginning, at rest.
    st.current.sway = 0
  }

  useFrame((_, dt) => {
    const c = controls.current
    const v = viewMode.get()
    const s = st.current
    const drawn = v.render === 'globe'
    if (c) c.enabled = drawn && v.view === 'globe' && v.phase === 'idle' && !s.glide
    if (!drawn) {
      s.drawn = false
      return
    }
    const aspect = size.width / Math.max(1, size.height)
    if (camera.aspect !== aspect) {
      camera.aspect = aspect
      camera.updateProjectionMatrix()
    }
    applyShift(s, camera, size, freeRect(size), dt)
    const now = performance.now() / 1000
    const key = `${v.seq}:${v.phase}`
    if (key !== s.phaseKey || !s.drawn) {
      // A new phase, or the first frame drawn: note where its motion starts.
      const arriving = !s.drawn
      const landed = s.phase === 'in' && v.phase === 'idle'
      s.phaseKey = key
      s.phase = v.phase
      s.drawn = true
      s.home = v.home
      s.seed = look.seed // flights aim at this world's poses every frame already
      s.glide = null
      s.lastInput = now
      if (c) settleControls(c)
      if (arriving) put(v.phase === 'in' ? closePose() : homePose())
      // Frames do not line up with the end of a flight, so its last frame can stop a little
      // short: land exactly on the home view.
      else if (landed) put(homePose())
      s.from = pose()
    }
    // While drawn, 'in' always heads for the planet and 'out' and 'fade' for the sector.
    if (v.phase === 'in') put(lerpPose(s.from, homePose(), smoother(progress(v, now))))
    else if (v.phase === 'out') put(lerpPose(s.from, closePose(), smoother(progress(v, now))))
    else if (v.phase === 'fade') put(closePose())
    else idle(c, s, now, dt, v)
  })

  function idle(c, s, now, dt, v) {
    // The 0 key, or a new world (Reset sim stays in the controls on the planet, and the new
    // seed moves the site): glide to the home view of the world that is up now.
    if (v.home !== s.home || look.seed !== s.seed) {
      s.home = v.home
      s.seed = look.seed
      if (c) settleControls(c)
      if (reducedMotion) put(homePose())
      else s.glide = { from: pose(), t0: now }
    }
    if (s.glide) {
      const t = (now - s.glide.t0) / HOME_GLIDE
      put(lerpPose(s.glide.from, homePose(), smoother(t)))
      if (t >= 1) s.glide = null
      s.lastInput = now
      return
    }
    if (reducedMotion || s.dragging || now - s.lastInput < SPIN_AFTER || !spin.current) return
    // A slow sway out and back (idleSway), not an endless turn, so the site, its card and the
    // day side stay in view however long the planet is left. A drag pauses it where it is,
    // and it carries on from there. The step is capped at 0.25 s, so a long frame (or a tab
    // coming back) cannot jump it far, while a slow software renderer still turns it.
    s.sway = (s.sway + ((Math.PI * 2) / SWAY_PERIOD) * Math.min(dt, 0.25)) % (Math.PI * 2)
    spin.current.rotation.y = idleSway(s.sway)
  }

  return (
    <OrbitControls
      ref={controls}
      enablePan={false}
      enableDamping
      dampingFactor={0.07}
      rotateSpeed={0.45}
      zoomSpeed={0.7}
      minDistance={MIN_DIST}
      maxDistance={MAX_DIST}
      minPolarAngle={0.25}
      maxPolarAngle={Math.PI - 0.25}
      onStart={() => {
        const s = st.current
        s.dragging = true
        s.lastInput = performance.now() / 1000
      }}
      onEnd={() => {
        const s = st.current
        s.dragging = false
        s.lastInput = performance.now() / 1000
      }}
    />
  )
}
```

- First frame after the fade (`in` via `fade`): start at the close pose.
- Instant switch (`idle` via `instant`): snap to home.
- Turn round mid-dive (`in` via `turn`): ease from the current pose.
- A new dive (`out`): start from wherever the user left the camera, and turn back to spin 0 on the short path.
- Left alone: after 8 s the sway eases out from spin 0 to `IDLE_SWAY` over a minute and back, again and again. The sun co-rotates with the planet (it is fixed in the planet's frame), and the sway only turns the camera's side towards it: at home the sun's cosine under the camera goes from 0.29 up to 0.57, and the site keeps facing the camera at 0.95 or more (the globe-math test checks 200 seeds). // Brings the sector back for things that do not go through App: a rover asking the
```js
// operator to pick a place (each such question once; one already open when the planet was
// asked for does not bounce it), and hazard placement started from anywhere. Returns the
// uninstall function. GlobeLayer installs it.
export function installViewGuards() {
  const seen = new Set()
  // Every place question in this state counts as seen, so none of them bounces the view.
  const noteAll = (s) => {
    seen.clear()
    for (const q of s.requests) if (hasPlaces(q)) seen.add(q.id)
  }
  let gen = simStore.get().gen
  noteAll(simStore.get())
  const offSim = simStore.subscribe(() => {
    const s = simStore.get()
    // A new init: Reset sim, or a reconnect, which re-sends the open questions with their
    // old ids (applyInit bumps gen either way). What it carries counts as seen; only place
    // questions that arrive after it bring the sector back.
    if (s.gen !== gen) {
      gen = s.gen
      noteAll(s)
      return
    }
    for (const q of s.requests) {
      if (!hasPlaces(q) || seen.has(q.id)) continue
      seen.add(q.id)
      leaveGlobe()
    }
  })
  const offApp = appStore.subscribe(() => {
    if (appStore.get().placing) leaveGlobe()
  })
  return () => {
    offSim()
    offApp()
  }
}
```

How `seen` behaves: a question that was open when the guard was installed, or that the guard has already seen, never bounces the view. So a question that stays open while the user opens the planet (the test's `q0`) does not send them straight back, and a question that arrived while the sector was up does not bounce a later visit to the planet. A new init refills `seen` from what it carries instead of bouncing: `applyInit` bumps `gen` on every init (`simState.js:524`), and the server sends one on every connection with the open `requests` (`mock-server.mjs:4214` and `:4466`), so a connection blip would otherwise throw the user off the planet for a question they had already left open on purpose. The cost: a place question that first appears inside a reconnect's init does not bounce the view, but its request card still shows.
